# Code of conduct

OTIS follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).
In short: be kind and patient, assume good intent, welcome newcomers, and
keep criticism about the work, not the person. Harassment, insults and
personal attacks aren't welcome here, in issues, pull requests or anywhere
else the project lives.

## Reporting

If someone's behavior in an OTIS space bothers you, tell the maintainer
privately. Use GitHub's private reporting (the repository's
[Security tab](https://github.com/WolfBrandon/otis/security) → **Report a
vulnerability**). It's meant for security problems, but it's also the private
channel this project has. Mention that it's a conduct report. For abuse that
breaks GitHub's own rules, you can also use GitHub's **Report content**
option on the comment or user.

Reports are kept confidential. The maintainer may edit or remove comments,
close discussions, or block people who don't follow this code.
